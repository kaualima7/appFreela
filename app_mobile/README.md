Nome do aplicativo - Freelike

Integrantes - Kauã Lima Rodrigues

Funcionalidades - login com conta de cliente, consulta à vitrine de serviços, visualização dos detalhes de um anúncio e opção de demonstrar ou retirar interesse pelo coração

Como rodar o aplicativo - na pasta de app_mobile, insira os seguintes comandos:

flutter pub get
flutter run
